
## Project Description

AirbnbDemo is a server-side rendered accommodation listing application built with Node.js, Express, MongoDB, Mongoose, and EJS. Users can view available listings, see listing details, add new properties, edit existing information, and delete listings through RESTful routes.
1.Database Set Up
2.REST Apis for CRUD

Model Listing
|\_title
|\_description
|\_image
|\_price
|\_location
|\_country

APIs

1.index Route ==>GET==>/listings

2.show specific listing Route ==>GET==>/listings/:id

3.New & Create Route Form ==>Get==>/listings/new

3.New & Create Route ==>Post==>/listings

4.Edit form Route ==>Get ==>listings/:id/edit

5.Update listing Route ==>Put ==>/listings



## Learnings

- Connected an Express application to MongoDB using Mongoose.

- Designed a Mongoose schema and model for accommodation listings.

- Built CRUD operations with RESTful routes.

- Used EJS and EJS-Mate to create reusable server-rendered views and layouts.

- Used form handling, `method-override`, static files, and responsive styling to create a complete web application workflow.
